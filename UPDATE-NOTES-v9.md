# Day Rush v9 — Dense dashboard

The empty lower half of Today is now useful:
- 7-day clickable schedule strip
- Each day shows total commitments/due items
- Weekly workload snapshot: due, events, open days
- Coming Up cards for the next three scheduled events
- Clicking a day jumps directly into that week in Calendar
- Clicking Coming Up events opens the existing event editor
- Existing personality/Canvas filtering retained
